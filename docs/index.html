Dated documentation for ClassLink Online supported capabilities and limits, plus integration guides.

ClassLink Online: supported capabilities (updated March 4, 2025)

Supported: assignments with due dates, file and text submissions, threaded discussions, scheduled live sessions, class rosters of up to 300 students, and grade passthrough to ProgressTrack.

Supported file types for submissions: PDF, DOCX, PPTX, JPG, PNG and MP4.

ClassLink Online: limits (updated March 4, 2025)

Live sessions: 60 participants maximum, 90 minutes per session. File size: 100 MB per file. Rosters: 300 students per class. Not supported: proctoring, content import from other systems, and offline mode.

Integration guides

Setup guides are available at /docs/integrations/slack, /docs/integrations/salesforce and /docs/integrations/hubspot.
